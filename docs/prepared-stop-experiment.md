# 停止準備からF001へ接続する実験

ブランチ: `experiment/prepared-f001-stop`。自然さの採否は人間の目視評価だけで決める。

残り1.2mから停止準備を表示する。評価済み状態が近く、基準Xの12cm手前から4cm先までの範囲に入った場合は現在の履歴から生成する。適合しない場合も残り60cm（短距離では開始時点）でA方式による停止生成を一度行う。後者は「未評価のA方式」と表示し、評価済み状態に一致したことにはしない。

停止準備中のWalk入力を小さくする処理は加えない。実際の減速はMotionBricksがF001へ生成する停止モーションで行う。クリックした目的地は維持し、目標補正・再生速度変更・大量生成・再試行は行わない。生成失敗時は失敗を表示して姿勢を保持する。

原本11候補と診断データは変更しない。参照候補、保存状態との差、実際の停止開始距離、現在の4姿勢、生成条件、元の目的地に対する到着誤差を保存する。新規動作の評価はすべて未確認で開始する。停止後は既存の接地判定とGroundedIdleへの移行を使用する。

## 試し方

`http://127.0.0.1:5188/` を再読み込みする。「停止準備 → F001接続（新実験）」が初期選択される。地面をクリックすると次の移動から適用する。前の厳密一致実験・従来方式にも切り替えられる。新実験はA方式の10候補を参照し、C方式は前の厳密一致実験に残す。

機能確認では2m・1m・30cm・50cm・方向変更後の5ケースで生成と再生が終端まで進んだ。前半2件と方向変更は残り約58〜59cm、短距離2件は開始時点で生成した。結果は `metrics/prepared-stop/functional-check.json`、画面は同ディレクトリのPNGに保存した。数値と自動テストは処理経路の確認用で、動作の自然さは判定していない。全ケースの人間による評価は未確認のまま。

Python 142件とWeb 31件のテストで、未一致時の生成、短距離、停止開始窓、失敗時に再試行しないこと、未評価表示を確認した。実生成の姿勢と参照条件は `metrics/visual-stop-runs/` に保持する。画像や通常画面を見て、人間が足の交差・足の浮き・膝・停止後のつながりを評価する。
