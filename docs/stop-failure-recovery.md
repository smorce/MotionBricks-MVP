# 停止失敗時の回復仕様

- 停止準備距離は接地予測距離と直近の合格停止モーションの実移動距離を用い、到達可能な最終歩幅以内に制限する。
- 初回停止生成が失敗した場合、表示済み姿勢を保持し、次のtickで残距離を評価する。通常Walkは再開しない。
- 残距離が8cmを超える場合、最大25cmの中間目標へ公式生成を試みる。支持足だけをピン対象とし、遊脚を解放する。
- 中間区間も通常の停止品質検証を通す。元の目的地から遠ざかる軌道、目的地を越える軌道、1cm未満しか近づかない区間は表示しない。
- 合格区間の再生後に残距離を再評価する。最大8区間とし、生成不合格・前進不足・上限到達時は到着失敗として姿勢を保持する。
- 支持足は低い足を優先し、同じ高さなら進行方向に対して後方の足を選ぶ。接地中の支持足は開始位置から2cm以内に保つ。
- ルートの瞬間移動、独自の関節補正は禁止する。目標姿勢の配置と生成フレームの表示を区別する。
- 画面にphase、goal_error_m、stop_prediction_m、final_stop_metrics.reason、stop_failure_reasonを表示する。生成段階と品質検証段階を区別して記録する。

25cm・8区間は回復の暫定上限であり、GPU実機で自然さと成功率を確認する。

## 骨長検証と足先診断

- ルートを除くローカル並進のノルムを開始姿勢と比較する。方向だけの変化では拒否しない。許容値は暫定で `0.002m + 0.01 × 開始骨長` とし、実生成の計測後に再評価する。
- `final_stop_metrics` に全関節の最大骨長誤差と位置変化量、許容値を `bone_length_diagnostics` として残す。各関節の `frame` は最大骨長誤差の0始まりフレーム、位置変化量は区間内最大値。失敗時の `failed_joint` / `failed_frame` は最初の許容値超過を示し、直下の変化量はその関節・フレームの値とする。
- 最大骨長誤差 `max_bone_length_error_m` と実際の `ik_pin_mask` を記録する。膝、貫通、接地滑り、着地、最終安定性の検証は維持する。
- ブラウザの `gait.foot_height_diagnostics` に左右の足首・足先についてSOMA/VRMの床基準高さと差を記録し、足先高さをステータスに表示する。接地表示はSOMA側の判定なので、この値を描画後のVRMの高さと比較する。足先ボーンの位置であり、靴底メッシュの高さではない。
- 再検証では公式生成の合否と骨長誤差を確認してから、到着誤差とCollect Stanceを確認する。停止予測距離は変更しない。
