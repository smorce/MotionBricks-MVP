# 最後の一歩と接地確認

停止距離への到達は停止要求とし、両足接地の確認を停止確定の条件とする。
待機中も公式Walkへの入力を維持して次フレームを生成する。停止要求時の方向を保持し、目的地通過による反転を防ぐ。
0.75秒で未接地ならWalk入力を終了し、`contact_recovery` に移る。公式生成器でF001への遷移を一度だけ生成する。公式Idleへの内部遷移はF001生成で置き換え、待機クリップをそのまま再生しない。生成期間の上限は4秒とし、終了後0.25秒の接地確認でも両足接地が得られなければ `stop_failed` で姿勢を保持する。正常停止・到着通知・GroundedIdleへの移譲は行わず、次の移動要求で再開できる。
接地観測はtickにつき一度、入力姿勢で行う。浮いた足は速度がゼロでも接地としない。
GroundedIdleへの所有権移譲にも両足接地情報を要求する。通常の収束歩は接地回復後だけ判定し、未接地時に判定済みにしない。

無効化中の手続き脚制御は回復に使用しない。停止要求後のWalk継続は最大0.75秒とし、接地判定が成立しなくても歩行入力を出し続けない。F001への回復は通常の収束歩とは別処理とする。
