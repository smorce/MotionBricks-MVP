# 最後の一歩と接地確認

停止距離への到達は停止要求とし、両足接地の確認を停止確定の条件とする。
待機中も公式Walkへの入力を維持して次フレームを生成する。停止要求時の方向を保持し、目的地通過による反転を防ぐ。
0.75秒で未接地なら `contact_recovery` に移り、失敗を記録して公式Walkによる接地回復を継続する。未接地の姿勢を保存せず、到着通知も出さない。
接地観測はtickにつき一度、入力姿勢で行う。浮いた足は速度がゼロでも接地としない。
GroundedIdleへの所有権移譲にも両足接地情報を要求する。通常の収束歩は接地回復後だけ判定し、未接地時に判定済みにしない。

公式Idleや無効化中の手続き脚制御は回復に使用しない。公式Walkの継続により停止位置を超える可能性があり、接地が得られない間は回復状態を維持する。
