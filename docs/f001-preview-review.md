# F001接続の目視確認

`http://127.0.0.1:5188/` 上部の「F001接続の確認パターンを見る（5種類）」から開く。
直進2m、旋回後2m、短距離約30cm、斜め接近約1.4m、小さな斜めずれ約74cmを固定再生する。
現在の停止準備 → F001接続で公式モデルから生成した結果であり、自然さは未評価。

移動条件で1種類を選び、再生、0.25／0.5倍速、正面／側面／斜め、時間スライダーで確認する。
「停止開始」「Idle移行」で該当時刻へ移動できる。全候補表示では先頭候補の時刻を使う。
緑の輪は元のクリック位置。各カードの「自然」「崩れ」とメモはブラウザに保存され、
「目視評価を保存」で候補IDと評価時刻を含むJSONを出力できる。

確認用データは `web/public/f001-previews.json`。追加推論は再生中に行わない。
VRMは既存の `http://127.0.0.1:8765/roze.vrm` を自動取得するためバックエンドを起動しておく。
再生成時は公式ランタイム環境で `backend/benchmark_arrival.py` の
`--preview-output web/public/f001-previews.json` を使う（出力先は作業ディレクトリ基準）。
停止条件の追加調整は保留し、人間の評価を次の改善の入力にする。
