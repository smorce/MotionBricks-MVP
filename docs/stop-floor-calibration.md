# 停止時の床面と足先校正

SOMAのワールド床面はZ=0mとする。初期化時のZ-up基準姿勢から左右の足首・つま先の床面オフセットを一度だけ校正し、rigの `stop_ground` で配信する。腰高や停止開始時の足先から床面を推定しない。

停止目標と検証で校正を共有する。各骨の床面からの高さからオフセットを差し引き、従来の貫通許容値2cmを適用する。最初の貫通について0始まりのフレーム番号、左右、部位、骨ワールド高さ、床面高さ、校正値、校正後の貫通深さ、腰高を記録する。VRM診断は靴底ではなく骨位置の床面からの高さを比較する。

基準姿勢が接地姿勢であることを前提とする。実機では同じ目的地で貫通詳細、両足着地、到着誤差8cm以内を確認する。停止予測、歩行速度、Collect Stance、脚補正、Idleは変更しない。
