# 停止の再現・診断・候補探索

## 実装

停止生成はライブ再生器を変更せず、候補ごとに新しい公式SOMACharacterと再生履歴を使用する。生成は公式 `generate_to_target_poses()`、足の補正は公式IK Pinのみ。手続き的な脚IKは使用しない。

停止前のJSONには全姿勢・ルート・32履歴と時間刻み・直近4記録姿勢・公式モデルの4入力姿勢・接地・足座標・床校正・目標・速度・停止予測・歩行位相・支持足・F001目標・推論設定・モデルSHA256・公式ランタイムのコミット・Python/NumPy乱数状態・VRM変換ソースとスライダー設定を保存する。既定保存先は `metrics/stop-replays`。変更は `MOTIONBRICKS_STOP_REPLAY_DIR`。

公式生成経路に乱数seed引数はない。候補間でライブのグローバル乱数を書き換えず、新しい再生器へ姿勢履歴と目標を復元する。実測11条件で再推論配列が完全一致した。直接1mの目標は生成前に拒否されるため配列比較対象外。別GPU・ドライバー・TensorRTでのビット一致は保証せず、比較差をJSONに記録する。異なるモデルSHA256の再現は拒否する。

## 診断と採用

骨長、身体基準の膝方向と角度、関節回転差と足裏反転、床貫通、接地区間の累積滑り、遊脚の持ち上げ・着地、ルート、到着誤差、末尾の足の安定を同時診断する。合否・測定値・フレームを保存する。不正配列の場合のみ形状検証で終了する。

基準は到着8cm、接地滑り2cm、床貫通2cm、骨長2mm+1%、ルート6cm/フレーム、末尾の足移動2mm。骨長は公式IKの数値誤差を含む許容値であり数学的な完全一致ではない。採用結果の最大骨長差は約0.49mm。足裏が下を向く反転も速度によらず拒否する。

遊脚の接地は公式モデルの信頼度0.5と校正高2cmから判定し、選んだ支持足は信頼度によらず継続監視する。2cm以上移動する遊脚には2.5cm以上の持ち上げを要求する。SOMA骨の代理点はVRMの靴底そのものではない。

開発時は左右支持・F001・腰高・生成長・段階的な持ち上げ/前進/着地から最大24候補。全滅時だけ腰高を細分化した最大12候補を1回再探索する。現在歩幅維持も生成アダプターで選べるが、初期探索で滑りが大きく既定の優先候補から外した。安全条件を満たす候補だけ、到着誤差・滑り・ルートの滑らかさ・膝角度変化を辞書式で比較する。足幅・クリアランス・末尾安定性も記録する。

通常は優先6候補を上限として最初の合格で終了する。全滅時は追加2候補、それでも失敗すれば現在位置での着地回復2候補まで。回復も同じ検証に通った動作だけ再生し、到着とは扱わず `stop_failed` と理由を残す。安全な回復が必ず生成できる保証はない。

## 実行

公式MotionBricksリポジトリを作業ディレクトリとし、`MOTIONBRICKS_ROOT` を設定する。`<repo>` はアプリの絶対パス。

```powershell
uv run --link-mode=copy python <repo>/backend/collect_stop_cases.py --output <repo>/metrics/stop-measured
uv run --link-mode=copy python <repo>/backend/run_stop_replay.py <repo>/metrics/stop-measured --output <repo>/metrics/stop-final
```

再推論CLIは単一JSONにも対応し、クリック不要。`stop_test_report.py` は生成結果を含むライブ保存JSONを再診断する。出力は `stop_diagnostics.json`、`stop_test_results.json`、`stop_test_report.html`。HTMLにはSOMA骨格の再生プレビューを含む。

## 検証結果

- 実測12条件を保存・検証した。左右遊脚・両足接地は実際の接地信頼度と高さ、大小歩幅は実際の足幅で選択。再歩行前は公式Idle。減速条件は入力強度を0.2に落とした状態であり、瞬間速度の単調減少は保証しない。
- 通常停止10条件で合格候補を取得。減速は限定再探索で合格。SOMA上の到着誤差は最大約1.5e-11m、接地滑り最大約1.51cm。
- 支持足固定で直接50cm・1mへ届かせる目標は安全に拒否。歩行計画全体を含む20cm・50cm・1m・旋回・再歩行の5試験はすべて `settled` に到着。
- Python 116件、JavaScript 27件成功。既存の骨長・床・滑り・膝・未着地・到着誤差・Idle保持・初回起動ゲートの回帰も実行した。
- ロゼVRMの歩行途中・停止後・再読み込み後を自動撮影し、画像を開いて確認。動画もローカル保存。確認例は両足接地、表示誤差0.000m。SOMA/VRM足先差は左右約1.6cm/3.6cmであり、全視点の靴底接触が完全という保証はない。
- 重複計算の最適化前は、合格1候補の停止生成・診断・保存が約1.75秒。常に4候補を評価した約6.1秒から短縮したが、生成開始時の待ち時間は残る。非同期先行推論は未導入。

最終的な自然さはロゼ実機確認で判断する。SOMA合格だけでVRM品質を保証しない。
