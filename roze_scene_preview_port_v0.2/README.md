### 1. 変更した内容

| 項目       | 以前         | 今回               |
| -------- | ---------- | ---------------- |
| 移動速度     | 歩行・走行の切り替え | 速度を滑らかに変化        |
| 停止判定     | 目的地まで36cm  | 現在の速度から停止開始距離を計算 |
| 停止動作     | 最終ポーズを直接指定 | 公式の停止遷移を利用       |
| 停止後      | ポーズを保持     | 自然な待機モーションを再生    |
| PoseLoom | 到着時に適用     | 停止完了後に生成して移行     |
| 位置補正     | 固定距離で判定    | 到着誤差を測定して表示      |

### 2. NVIDIA公式コードを再利用

今回の中心となるのは、次の3つです。

* `MovementControl`：移動速度と方向を滑らかに変化させる
* `LocomotionState`：歩行中の動作を継続して生成する
* `IdleState`：歩行から待機モーションへの移行を生成する

さらに `SOMACharacter.generate_clip_transition()` を利用して、停止後の待機モーションへ自然につなぎます。

これらはScene Previewで実際に利用されている処理です。([GitHub][1])

### 3. 停止位置の調整も可能

`backend/click_planner.py` に停止距離の設定を追加しました。

```python
stop_lead_seconds = 0.78
```

これは停止を開始するタイミングを決めるための実験用設定です。

**目的地を通り過ぎる場合は0.90へ、手前で止まりすぎる場合は0.65へ変更**して比較できます。

また、停止後の目標地点との距離も画面に表示します。
